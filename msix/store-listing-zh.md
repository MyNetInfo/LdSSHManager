## 长描述 (Long description, 推荐 200-800 字符)

**LdSSHManager** 是一款开源的桌面 SSH 会话管理工具，基于 Wails v2 + Go + Vue 3 构建，专为多主机运维与远程开发场景打造。

**核心功能**
- 🌳 会话树分组管理：外网/内网/自定义分组，双击一键连接，支持导入导出
- 🖥️ 多标签终端：xterm + WebGL 渲染，TUI / top / vim 等高频重绘场景更清晰流畅
- ⌨️ 快捷命令库：分类管理常用命令片段，一键执行
- 📁 SFTP 文件管理：内置文件管理器，浏览 / 上传下载 / 重命名 / 删除，终端 cd 自动联动
- ☁️ 云端同步（端到端加密）：会话 / 快捷命令 / 配置加密上传云端，多端共享、版本回溯
- 🌐 代理连接：适配受限网络环境

**安全有保证**
- 🔐 本地数据库 SQLCipher 全库加密（AES-256），锁屏密码保护
- 🔑 云端同步独立加密密码，上传前本地加密，云端仅存密文，端到端隔离
- 🧡 完全开源（MIT），源代码公开，无黑盒、无后门，可自行审计构建

**支持平台**：Windows 10/11 x64（本商店版本），另提供 Linux 与 macOS 版本。
