## Long description (recommended 200-800 chars)

**LdSSHManager** is an open-source desktop SSH session management tool built with Wails v2 + Go + Vue 3, designed for multi-host operations and remote development.

**Key Features**
- 🌳 Session tree with groups: external / internal / custom folders, double-click to connect, import & export support
- 🖥️ Multi-tab terminal: xterm with WebGL rendering, smooth for TUI / top / vim high-refresh scenarios
- ⌨️ Quick command library: organize and run common command snippets with one click
- 📁 SFTP file manager: browse, upload/download, rename, delete; auto-follows your terminal `cd`
- ☁️ Cloud sync (end-to-end encrypted): sessions / quick commands / configs encrypted before upload, share across devices, version rollback
- 🌐 Proxy support: works in restricted networks

**Security You Can Trust**
- 🔐 Local database fully encrypted with SQLCipher (AES-256), lock-screen password protection
- 🔑 Independent cloud encryption password: data encrypted locally before upload, cloud stores ciphertext only — fully isolated
- 🧡 Completely open source (MIT): auditable, no black box, no backdoors, build it yourself if you want

**Platforms**: Windows 10/11 x64 (this Store version); Linux and macOS builds also available.
